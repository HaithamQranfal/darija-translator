Darija Translator — REST API

LLM-powered RESTful web service (Jakarta REST + Jakarta Authentication) translating text to Moroccan Arabic (Darija).

  • GET api/health — public
  • POST api/translator/translate — HTTP Basic auth, JSON {"text":"..."}
  • GET api/translator/translate?text=... — HTTP Basic auth
  • GET api/translator/whoami — HTTP Basic auth
curl -u haitham:darija2026 -H "Content-Type: application/json" \
  -d '{"text":"How are you today?"}' \
  http://localhost:8080/translator/api/translator/translate
